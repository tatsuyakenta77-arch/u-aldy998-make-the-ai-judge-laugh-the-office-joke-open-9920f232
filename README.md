One line, 102 characters — one joke about office life:

> The fire alarm went off during the all-hands, and it was the only meeting all year that ended on time.

The fire alarm is the setup and "ended on time" is the payoff: the one meeting that finished on schedule is the one a fire alarm cut short. Everyone who has sat through an all-hands knows meetings never end on time — the alarm is the only thing that can actually end one. No reply-all, no printer, no "this meeting could have been an email" — the familiar setup is left alone and the turn lands on the last clause.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the single line to `/output/entry.txt` and prints exactly that line to stdout. No network, no randomness — every run writes the same bytes.
